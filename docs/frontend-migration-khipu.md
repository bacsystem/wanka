# Frontend migration to khipu-design-system (contract)

Status: proposed · 2026-11-17 · base `main` e1cd481, DS v0.5.23 · decision record: [ADR 0010](architecture/adr/0010-frontend-khipu-migration.md) · dependency graph: [`frontend-migration-khipu.mmd`](frontend-migration-khipu.mmd).
Owner rules (fixed): the app only uses DS components; no exceptions; no styles outside DS tokens/recipes; anything missing goes to the DS (PR + tag). Inputs: QA UI audit (counts re-measured on e1cd481: `ui/button` 97 files, `shared/status-badge` 90, `section-card` 59, `page-header` 52, `stat-card` 36, `data-table` 30, `sonner` 71 files / 249 `toast.*` calls, `lucide-react` 131 files, `recharts` 11 files, 13 native `type="date"`).

## 1. Strategy

- **Primitives (`components/ui/*`): direct codemod, no adapter.** Same base (Base UI + cva) and same variant names (`default|outline|secondary|ghost|destructive|link`); only `size="icon-sm|icon-lg"` maps to `icon` (all `h-control`). An adapter would add indirection for nothing.
- **Shared building blocks (`components/shared/*`): thin temporary adapters, then direct use per module.** `DataTable`, `StatCard`, `StatusBadge`, `SectionCard`, `PageHeader` have 30–90 call sites spread over every module; flipping their API in one PR collides with every module PR. The adapter keeps Wanka's props, renders only DS components (zero own classes) and is `@deprecated`. The whole app gets the DS look in one PR per family; modules then move to the DS API one by one; W8 deletes the adapters. Adapters get no new props.
- **Icons, hardcoded styles and `font-mono` on money are fixed inside each module PR**, not in global sweeps: one touch per file, no cross-PR conflicts. A ratchet baseline (§3) proves progress and blocks regressions from day one.
- **File ownership:** W2–W4 codemods exclude `components/shared/**` (W5) and `components/layout/**`, `app/**/layout.tsx`, `features/platform-admin/components/admin-shell.tsx` (W7). A local `ui/*` file is deleted by the PR that removes its last import.
- **DS bumps** (`apps/web/package.json` + `pnpm-lock.yaml`) are a one-line serial PR each (`chore(web): khipu-design-system vX`), never inside a feature PR, so parallel PRs do not fight over the lockfile. Each DS PR ships its own tag; "waits DS-x" = the first tag that contains it.
- UI-only change: no server, hot path or capacity impact, so no load test. Verification is unit + E2E + review screenshots.

### 2.1 Responsive contract after W7 (replaces CLAUDE.md "Responsive contract")

- ≥1280: DS floating sidebar 248 px; dashboard grid 2/3 + 1/3.
- 768–1279: DS rail 64 px with tooltips (auto; the user can expand, remembered); tables scroll inside their container (`anchoMinimo`).
- ≤767: no sidebar, no hamburger; `BarraInferior` (Inicio, Ventas, Clientes, Inventario, Más → drawer with the full `SidebarContent`), FAB "Nueva venta"; KPIs `FilaMetricas desplazable`; lists `tarjetaMovil`.
- Tenant selector, theme/appearance and user menu live in the sidebar (DS), not in the top bar. Page titles stay in `CabeceraPagina` (actions keep their client state); the top bar holds search, notifications and global actions.

## 3. DS gaps: decision and API contract (Spanish names, DS conventions)

Adopt DS behavior (no DS change): dialogs do not close on outside click (`ui/dialog.tsx:12-17`); no row density toggle (one row height); KPI icons without tinted box (DS §20 "Iconos"); `StatCompact` → `Metrica`; NotFound/Forbidden/SessionExpired/Error → `EstadoVacio` + `Alerta` composed in Wanka; area chart gradient → `area` below.
Add to DS:
- **DS-A `TablaDatos`/`TablaListado`** (new optional props, backwards compatible): `tarjetaMovil?: (fila: T) => ReactNode` — below `md` renders `<ul role="list" aria-label={titulo}>` with one card per row instead of the table; search, filters, sort, pagination and `seleccion` still apply; with `onFila` the card is a `<button>` only if it has no interactive children, otherwise a `div` with a primary link. `anchoMinimo?: string` (rem) → table `min-width` inside an `overflow-x-auto` container. `pie?: Partial<Record<idColumna, ReactNode>>` → `<tfoot>` totals row on visible columns (mobile: summary card at the end). `filaActiva?: string` (a `clave`) → `aria-selected` + `accent` band (§12). Columns menu: `ocultable: false` shows "Fijo" (`textos.fijo`), new item "Restablecer" (`textos.restablecer`) restores `ocultaInicial`; `claveAlmacenamiento?: string` persists visible columns in `localStorage` (try/catch).
- **DS-B shell:** `Shell rail?: "auto" | "nunca"` (default `"nunca"`). `"auto"`: CSS-driven 64 px rail at 768–1279 (no hydration flash); toggle `BotonRail` in the sidebar header (`aria-expanded`, `aria-controls`, "Contraer menú"/"Expandir menú"); preference `localStorage["khipu-sidebar-rail"] = "rail" | "expandido"` applied before paint by `ScriptDiseno` as `html[data-rail]`. In rail: items icon-only with `Tooltip side="right"` and `aria-label`, group titles hidden, collapsible groups flattened, `selector`/`usuario` as avatar triggers, active item `PESO_ICONO_ACTIVO`. `BarraInferior({ items: ItemNav[] /* ≤ 4 */, mas?: { etiqueta: string; contenido: ReactNode }, accion?: { href: string; etiqueta: string; icono: IconoComponente }, etiqueta?: string /* "Navegación principal" */ })`: `<nav aria-label>` fixed bottom, only `<md`, items ≥ 44 px (`OBJETIVO_TACTIL`), active by prefix with `aria-current="page"`; "Más" opens the `MobileNav` drawer with `contenido`; `accion` is the FAB (`ACCION_PRINCIPAL`, round, above the bar, `aria-label`); safe-area inset; `Shell barraInferior?: ReactNode` pads `main` and toasts. `TopBar migaComoTitulo?: boolean` (default `true`); `false` renders the breadcrumb as `<nav aria-label={etiquetaUbicacion}>` text, not `h1` (the portal's admin top bar can then drop its copy).
- **DS-C:** `CentroNotificaciones({ notificaciones: Notificacion[]; onLeer?: (id) => void; onLeerTodas?: () => void; verTodas?: { href; etiqueta }; textos?: Partial<TextosNotificaciones> })`, `Notificacion = { id: string; titulo: string; descripcion?: string; fecha: string /* ISO */; tono?: Tono; icono?: IconoComponente; href?: string; leida: boolean }`. Trigger `size-control` bell, unread dot + `aria-label` "Notificaciones, 3 sin leer"; `Popover` 360 px (full width `<md`), `ScrollArea`, items are links, empty → compact `EstadoVacio`, dates with `formatearFechaHora`. `TabsRuta({ items: { href: string; etiqueta: ReactNode; contador?: number; exacto?: boolean }[]; etiqueta: string; estilo?: "linea" | "segmentado" })`: `<nav aria-label>` of `Link`s with `aria-current="page"` (not `role="tablist"`: they are routes), same look as `Tabs`, horizontal scroll on mobile with the active one scrolled into view.
- **DS-D `feedback/toast`:** export `toast = { ok, aviso, error, info, promise, cerrar }` (same signatures as `useToast()`, which returns this object) backed by a module store the `ToastProvider` subscribes to; callable from handlers and column renderers outside hooks; calls before mount are queued (max 5). Max 3 visible, bottom-right (`≥md`), bottom-center above `BarraInferior` (`<md`); `error` is `aria-live="assertive"`, the rest `polite`.
- **DS-E:** `EntradaDecimal({ id; valor: number | null; onCambio: (v: number | null) => void; min?; max?; decimales?: number /* 2; 0 = entero */; sufijo?: ReactNode /* "%", "kg" */; alinear?: "izquierda" | "derecha"; disabled?; "aria-label"? })`: keeps the raw text while focused, accepts `.` or `,` as the single decimal separator, commits the parsed value on each change, normalizes and clamps to `max` on blur, `inputMode` decimal/numeric, `h-control`, Inter `tabular-nums`. Also fix `EntradaMonto`: `replace(/[^\d.]/g, "")` (`src/components/formularios/entrada-monto.tsx:52`) turns "12,5" into 125.
- **DS-F:** `GraficoBarras apiladas?: boolean` (tooltip shows the total); `GraficoLineas area?: boolean` + `Serie.discontinua?: boolean` (goal/projection); `GraficoDona({ partes: { nombre; valor; detalle? }[] /* ≤ 5, caller groups "Otros" */; centro?; titulo?; formato?; etiquetadoPor?; descripcion?; tamano? })` with `--chart-1..5` and `--chart-trazo-*` borders, value and % in legend and `<title>`; `Kpi sufijo?: ReactNode`; `FilaMetricas desplazable?: boolean` (`<md`: snap scroller, cards min 11 rem, `role="region"` + `aria-label`, `tabIndex=0`).

## 4. Guard rails

- ESLint `no-restricted-imports` (W1, suppressions baseline via ESLint ≥ 9.24 bulk suppressions, `--prune-suppressions` after each PR): `lucide-react`, `sonner`, `recharts`, `cn`, `class-variance-authority`, `@base-ui/react/*` (outside the DS), `@/components/ui/*`, `@/components/shared/*`, `next-themes` outside `components/providers`.
- `pnpm lint` = `eslint . && khipu-ds verificar tipografia alturas estilos iconos --dir src --base ds-baseline.json`. Keep `lib/design-system.test.ts` (palette colors, `:root`). Baselines only shrink; W8 deletes them.
- **No CI exists in Wanka (`.github/` has no workflows): the guards are advisory until the tech-lead adds one running lint, typecheck, test and E2E on PRs.**
- CLAUDE.md text (W8 replaces "UI conventions", "Visual language" and "Responsive contract"; net size goes down):
  > **UI = khipu design system only.** Every UI piece is imported from `khipu-design-system/*`; Wanka code composes DS components with data and text. Never a local copy, a look-alike component or a `className` that overrides a DS component. Missing component or variant → PR to bacsystem/khipu-design-system, tag, bump. Styles only with DS tokens, the named type scale and `@/lib/estilos` recipes: no `[...]` values, hex/rgb, palette colors, inline `style`, `z-*`, own shadows/radii/durations or Tailwind text sizes. `font-mono` only for identifiers (series-correlativo, SKU, ids); amounts, dates, RUC and quantities are Inter `tabular-nums`. Icons: Phosphor (`PESO_ICONO*`; server components from `@phosphor-icons/react/dist/ssr`). Toasts: `toast` from `khipu-design-system/feedback/toast`. `pnpm lint` enforces it.

## 5. Risks

- **Next 16 peer:** DS declares `next ^15.5`; Wanka forces it with `peerDependencyRules` (root `package.json:15-19`). The DS nav (`next/link`, `usePathname`) is only tested on Next 15: DS-0 must add a Next 16 smoke app before W7; W8 removes the rule.
- **User-visible changes:** dialogs ignore outside clicks (Escape/X/footer still close); new toast look and position; rail stored in `localStorage` instead of the `sidebar_state` cookie; tenant switcher and user menu move to the sidebar; density toggle gone; amounts switch from mono to Inter; KPI icon boxes gone; lists gain search/CSV/print; date fields become the DS calendar. Release note per PR.
- **E2E that will break:** `data-slot` selectors in `dashboard.spec.ts:15,20,37`, `pos.spec.ts:8`, `admin.spec.ts:55` (rewrite to `getByRole("navigation", { name })` + `html[data-rail]`, in W7); bottom nav name (`dashboard.spec.ts:16`) and "Más" (`interactions.spec.ts:155`) keep their names via `BarraInferior`; native date fills (13 fields, W3); "Columnas"/"Restablecer" via DS `textos`.
- **DS bottleneck:** W5b, W6.x and W7 wait for DS tags; W2–W5a proceed meanwhile. A DS gap found mid-module goes to the DS; never a local workaround.
- **Bug to avoid now:** do not use `EntradaMonto` until DS-E (decimal comma).
